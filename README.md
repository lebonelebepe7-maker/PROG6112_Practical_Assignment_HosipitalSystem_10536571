# PROG6112_Practical_Assignment_HosipitalSystem_10536571

 Medicare Hospital Admission System is a Java-based console application designed to manage patient admissions, bed allocations, and ward reporting for a healthcare facility. Built using object-oriented programming (OOP) principles, the system streamlines hospital administrative tasks by organizing patient records across different care categories and tracking bed availability in real-time.Key FeaturesPatient Management.
 
##(Features 1 & 4):
Register new patients across distinct categories (INPATIENT, OUTPATIENT, EMERGENCY).Utilizes class inheritance for Inpatient records to track specific ward details.Search, update, and delete patient records using unique Patient IDs with duplicate prevention.Display a comprehensive list of all registered patients.Bed Management.

##(Feature 2):
Manages a $4 \times 5$ grid layout representing 20 hospital ward beds (B01 to B20).Restricts bed allocations strictly to registered INPATIENT category records.Releases occupied beds upon patient discharge or record deletion.Displays complete ward layouts, available beds, and occupied bed statuses.Reporting.

##(Feature 3):
Generates administrative ward reports summarizing total registered patients.Calculates real-time bed occupancy counts and total ward occupancy percentage.Automated Unit Testing.

##(Feature 5):
Fully integrated JUnit test suite verifying patient registration logic, bed allocation rules, and calculation accuracy.Project Structure.
